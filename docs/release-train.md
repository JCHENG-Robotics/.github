# 发布列车

| 渠道 | 用途 | 签名 | 允许实机 |
|---|---|---|---|
| `dev` | 每日构建、接口试验 | 否 | 否 |
| `rc` | 候选发布、验收 | 是 | 仅受监督验收 |
| `stable` | 生产基线 | 是 | 是，按运行手册 |

发布顺序：契约 -> 系统 -> 模块 -> 应用。每个 `stable` 发布绑定：

- 锁文件快照（仓库提交、契约哈希、镜像摘要、机器人配置哈希）。
- SBOM 与 SHA-256 校验和。
- E2E/验收报告与证据索引。
- 回滚演练记录。

标签不可移动；发布从标签构建，不从分支头构建。详细规则见
`jcheng-manipulation/docs/ecosystem/05-versioning-lock-release.md`。
