# Real CLI Integration Report

> Fixed main and candidate SHAs are listed in 42. All commands are offline; no
> device, DDS, ROS or network service is used.

## 1. Method

Pristine main trees were extracted with `git archive origin/main` for devices,
scenarios, applications, benchmark and simulation. Artifacts were generated by
the repository CLIs, not hand-edited:

```bash
# devices
PYTHONPATH=src python3 -m jcheng_devices --root . \
  snapshot hiwonder.armpi-ultra --output .../arm.yaml
PYTHONPATH=src python3 -m jcheng_devices --root . \
  snapshot hiwonder.armpi-ultra-gripper --output .../gripper.yaml
PYTHONPATH=src python3 -m jcheng_devices --root . \
  snapshot intel.realsense-d435i --output .../camera.yaml

# scenarios
PYTHONPATH=src python3 -m jcheng_scenarios requirements ore_sorting --root . \
  --output .../requirements.json

# applications
PYTHONPATH=src:scripts python3 scripts/armpi_ore_sorting_reference.py \
  --device-snapshot arm=.../arm.yaml \
  --device-snapshot gripper=.../gripper.yaml \
  --device-snapshot camera=.../camera.yaml \
  --scenario-requirements .../requirements.json \
  --out .../reference \
  --benchmark-root <benchmark checkout> \
  --simulation-root <simulation checkout>
```

Evidence: `/tmp/b1-evidence/main-b1e0706/` and
`~/jcheng/phase2/baseline1-acceptance-20261128/`.

`content_hash`; the scenario requirements carry distinct
`provenance.scenario_content_hash` and `content_hash`.

## 3. Negative results

| Test | Result |
|---|---|
| Edited device snapshot (data field changed, old hash kept) | `STALE_DEVICE_HASH`, exit 1 |
| Missing gripper role | `NO_DEVICE_FOR_ROLE`, exit 1 |
| Arm DOF threshold 6 vs device 5 | `INCOMPATIBLE_PARAMETER`, exit 1 |
| Threshold unit `cm` for DOF | `INCOMPATIBLE_UNIT`, exit 1 (candidate PR) |
| Unknown/optional capability | explicit `optional_absent`, not assumed |
| Algorithm requirement | `deferred`, never matched to a device |
| Unauthorized mock run | `ABORTED`, zero execute requests (PR #20) |

A YAML comment edit does **not** change the content hash, because comments are
not data; the stale test edited a data field, not a comment.

## 4. Reproducibility

`.github/dev/baseline1-acceptance.sh` (workspace entry `~/jcheng/dev/baseline1-acceptance.sh`) runs the same chain and gate assertions
with root overrides:

```bash
DEVICES_ROOT=... SCENARIOS_ROOT=... APPLICATIONS_ROOT=... \
BENCHMARK_ROOT=... SIMULATION_ROOT=... OUT=... \
bash .github/dev/baseline1-acceptance.sh
```

The candidate run completed the reference, the eight-case mock task and the
three benchmark discriminations with exit 0.
