# 实机工作流

## 绝对规则

1. **任何实机运动都需要 Owner/Operator 的单独、明确授权。**
   授权按会话生效，不跨会话；CI、PR、脚本不得默认触发。
2. 运动只允许通过 `jcheng_motion` 的 `ExecuteMotion` 入口。
3. 能力模块不得发布厂商话题、打开串口或加入硬件 DDS 域。
4. 停止 / 锁存 / 未知结果必须按 `jcheng_safety` 的语义处理，不得自动重试运动。
5. 厂商容器启动检查会移动机械臂；不得自动重启厂商容器。

## 每次会话

- [ ] 物理：工作区清空、机械臂有支撑、无人员接触、电源正常。
- [ ] 链路：有线网络、DDS 发现、时钟偏移在阈值内。
- [ ] 栈：厂商节点已运行；安全节点 `STOP_LATCHED=false`；总线实测与缓存对齐。
- [ ] 版本：锁文件、契约哈希、profile 哈希与部署一致。
- [ ] 证据：日志/录屏目录就绪；操作员与监督人确认。
- [ ] 授权：Owner/Operator 明确批准本次运动范围。

## 禁止

- 用“软件停止”表述为“急停”。
- 在未确认 publisher 集合时同时启动两套运动服务。
- 用缓存位置代替总线实测。
- 在未完成根因分析前重跑同一失败场景。
